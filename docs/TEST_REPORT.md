# รายงานการทดสอบ

วันที่ 24 ตุลาคม 2569 (Asia/Bangkok)

สภาพแวดล้อม: Python 3.13, Streamlit 1.65.0, Pandas 3.0.6, Plotly 7.1.0

## ผลตรวจสอบ

- `python -m pip install -r requirements.txt` ผ่าน: มี dependency ครบแล้ว
- `python -m compileall -q app.py src tests` ผ่าน
- `python -m unittest discover -s tests -v` ผ่าน 8 tests หลังแก้ไขครั้งสุดท้าย
- ตรวจแถวจริง 29,530 แถว, คีย์ขัดแย้ง 1,080 คีย์, ไม่มีคีย์ซ้ำในตารางที่ใช้
- ตรวจทุกค่าที่แสดงต้องปรากฏในคอลัมน์ต้นฉบับ ไม่มีค่าที่สร้างขึ้นใหม่
- ตรวจว่าไม่สร้างยอดรวมจำนวนผู้มีงานทำ, ไม่มี annual wage ที่ผ่านข้อขัดแย้ง
- ทดสอบตัวกรองร่วม 2567 + Q1 + ภาคเหนือ + หญิง + ในเขตเทศบาล + 20–24 ปี
- ทดสอบ selection หลายจุด ปี/ไตรมาส และป้องกัน event เดิมสร้างการเปลี่ยนสถานะซ้ำ
- Streamlit AppTest: เปิดแอป, มี KPI 4 ใบ, เปลี่ยน widget ปี/ไตรมาส/ภูมิภาค/เพศ, reset แล้วตัวกรองว่าง, เปลี่ยนชุดภูมิภาคได้โดยไม่ exception
- เปิด Streamlit จริงบน localhost:8502 และตรวจใน browser
- คลิกแท่งภาคเหนือในแท็บภูมิภาค: chip ภูมิภาคเปลี่ยนเป็นภาคเหนือ และ KPI ค่าจ้างเป็น 13,603.17, การมีงานทำ 65.37, ว่างงาน 1.10 สำหรับ 2566 Q4 ยืนยันการกรองจากกราฟจริง
- ตรวจหน้าจอและแก้ไข KPI ที่ตัดข้อความด้วยการลดขนาดตัวเลข

## ขอบเขตและข้อจำกัด

การรันทดสอบและ server ภายใน sandbox ค้างก่อนเริ่มทำงาน จึงใช้การรันนอก sandbox ที่ได้รับอนุญาต การรันดังกล่าวผ่าน ไม่ได้ยืนยัน box/lasso ทุกกราฟด้วย browser แต่ทดสอบตัวประมวลผลหลายจุดและคลิกกราฟจริงแล้ว ยังไม่ได้ตรวจหลายอุปกรณ์หรือทุก browser และยังไม่มีเอกสารหน่วยจากผู้ผลิตข้อมูล
