# ข้อกำหนดแดชบอร์ด

3 แท็บ: ภาพรวม / ภูมิภาค / กลุ่มแรงงาน พร้อม sidebar และ KPI 4 สีตามภาพอ้างอิง

1. แนวโน้มอัตราการมีงานทำและว่างงาน: แสดงค่ารายไตรมาสจริง แยกรายปีออก
2. ค่าจ้างตามเวลา: ไม่สร้างค่าเฉลี่ยปี
3. ฤดูกาลว่างงาน: ตารางสีรายปี–ไตรมาส พร้อมเลือกช่วงผ่าน sidebar (heatmap ไม่มี event ที่เชื่อถือได้)
4. จำนวนผู้มีงานทำ: หน่วยต้นฉบับ ไม่มีการรวมหมวดหมู่
5. จัดอันดับภูมิภาค: แท่งแนวนอน ใช้พื้นที่/เพศ/อายุรวมที่มีจริง
6. Scatter ค่าจ้างกับว่างงาน และค่าจ้างกับการมีงานทำ: จับคู่บนทุกมิติที่ตรงกันเท่านั้น
7. ค่าจ้างชายหญิง, ค่าจ้างตามอายุ, ว่างงานตามอายุ, เปรียบเทียบพื้นที่: ค่าตรงจากข้อมูล ไม่มีการประมาณ

กราฟเปรียบเทียบต้องเลือกปีเดียวและไตรมาสเดียว (รวม quarter=0 สำหรับค่าจ้างรายปี) หากไม่พร้อมให้คำแนะนำ แทนการเฉลี่ยข้ามเวลา

## การเลือกข้ามกราฟ
ใช้ st.session_state และ Plotly on_select callable โดย callback ทำงานก่อนวาด widget กราฟส่ง customdata ของมิติที่รองรับ (เวลา ภูมิภาค เพศ อายุ หรือพื้นที่) คลิกจุด/แท่งหรือใช้ box/lasso สามารถเลือกหลายค่าในมิติเดียว (OR) และกรองข้ามมิติ (AND) กราฟแสดงเฉพาะข้อมูลที่ตรงทุกตัวกรอง

ตัวกรองว่างในมิติหมวดหมู่หมายถึงรวม สำหรับแกนเปรียบเทียบที่ยังไม่เลือกจะแสดงหมวดหมู่ที่ไม่ใช่รวม เมื่อเลือกแล้วจะแสดงเฉพาะที่เลือก ไม่มีการยกเว้นตัวกรองที่ใช้งาน

เพิ่ม revision เมื่อผู้ใช้เปลี่ยนตัวกรอง สร้าง key กราฟใหม่เพื่อล้าง selection เก่า ไม่เขียนทับสถานะ read-only ของ Plotly และไม่เปลี่ยน key ของ widget หลังสร้างใน run เดียวกัน Reset ทำงานผ่าน callback ก่อน run

เอกสาร API: https://docs.streamlit.io/develop/api-reference/charts/st.plotly_chart
