# ตลาดแรงงานไทย · Labor Intelligence

แดชบอร์ดภาษาไทยด้วย Python + Streamlit + Pandas + Plotly ใช้ข้อมูลจริงในคลังนี้ พร้อมตัวกรองร่วม ปี ไตรมาส ภูมิภาค พื้นที่ เพศ และอายุ

## เริ่มใช้งาน

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

เปิด URL ที่ Streamlit แสดง (ปกติ http://localhost:8501) รันจากโฟลเดอร์โครงการ ใช้ Python 3.11 ขึ้นไป ทดสอบจริงด้วย Python 3.13

## วิธีใช้งาน

- เริ่มต้นด้วยช่วงล่าสุดที่มียอดรวมหลายตัวชี้วัด ใช้แถบซ้ายเปลี่ยนช่วงเวลา
- ไม่เลือกหมวดหมู่หมายถึงใช้แถวรวมที่มีจริง ไม่ได้รวมแถวย่อยแทน
- คลิกจุดหรือแท่งบนกราฟ หรือใช้ box/lasso เพื่อเลือกหลายค่า ตัวกรองมีผลกับทุกกราฟที่เข้ากันได้
- เลือกปีเดียวและไตรมาสเดียวเพื่อดูแท็บภูมิภาคและกลุ่มแรงงาน
- ล้างปีและไตรมาสเพื่อดูแนวโน้ม กดล้างตัวกรองทั้งหมดเพื่อเริ่มใหม่
- KPI ใช้ช่วงล่าสุดที่ตรงเงื่อนไข และแสดงเฉพาะระเบียนเดี่ยว ไม่รวม/เฉลี่ยหลายกลุ่ม
- ตารางสีใช้ตัวเลือกปีและไตรมาสใน sidebar แทน event จาก heatmap
- ดาวน์โหลดข้อมูลที่กรองและคีย์ขัดแย้งจากส่วนตรวจสอบข้อมูลด้านล่าง

## ข้อมูลและข้อจำกัด

ต้นฉบับ `final_labor_master_data(1).csv` ไม่ถูกแก้ไข มี 29,530 แถว ไม่พบ metadata ยืนยันหน่วยหรือแหล่งผลิต จึงแสดงหน่วยต้นฉบับ ต้องยืนยันหน่วยก่อนใช้ตัดสินใจ ไม่มีการแทนค่าขาดด้วยศูนย์หรือข้อมูลสมมติ

ชุดภูมิภาคแยกกัน ไม่จับรวมข้ามนิยาม 1,080 คีย์ตัวชี้วัดมีค่าขัดแย้งและถูกตัดออก รวมถึงค่าจ้างรายปีทั้งหมด ข้อมูลจำนวนผู้มีงานทำบางชุดไม่มีพื้นที่หรือยอดรวม จึงอาจไม่แสดง KPI ไม่สร้างแผนที่ อุตสาหกรรม หรือจำนวนผู้ว่างงานที่ไม่มีข้อมูลรองรับ Kanit โหลดจาก Google Fonts ต้องใช้อินเทอร์เน็ต หากโหลดไม่ได้ใช้ sans-serif

อ่าน [DATA_AUDIT](docs/DATA_AUDIT.md), [DASHBOARD_SPEC](docs/DASHBOARD_SPEC.md), [TEST_REPORT](docs/TEST_REPORT.md) และ [PROJECT_STATUS](docs/PROJECT_STATUS.md)

## ทดสอบ

```bash
python -m unittest discover -s tests -v
python -m compileall -q app.py src tests
```

## โครงสร้าง

`app.py` จุดเริ่มต้น; `src/data_loader.py` ตรวจคีย์/ค่า; `src/metrics.py` เลือกระดับข้อมูล; `src/filters.py` สถานะร่วม; `src/charts.py` กราฟและ selection; `src/styles.py` ธีม; `docs/` เอกสาร; `tests/` การทดสอบ

ข้อมูลเดิมคงอยู่ที่ราก repository; `data/raw/` และ `data/processed/` สำรองสำหรับงานต่อไป โดยไม่ทำสำเนาหรือย้ายข้อมูลเดิม
